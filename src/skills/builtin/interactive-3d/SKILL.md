# Interactive 3D

Use 3D only when it strengthens the product concept and remains performant and accessible.

- Prefer lightweight libraries such as Three.js only when needed.
- Keep geometry and textures modest; lazy-load heavy assets.
- Provide reduced-motion alternatives and keyboard-accessible controls.
- Test rendering on mobile and low-end devices.
- Do not use 3D as decoration that harms usability.
