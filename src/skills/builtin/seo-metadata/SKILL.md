# SEO Metadata

Implement accurate, consistent metadata for web pages.

- Give every page a unique, descriptive title and meta description.
- Set canonical URLs and avoid accidental duplicate indexable URLs.
- Use robots directives intentionally; prevent staging/private pages from indexing.
- Add Open Graph and social metadata consistently.
- Use structured data only when it accurately represents page content.
- Keep server-rendered and client-rendered metadata consistent.
- Do not fabricate metadata or promise ranking improvements.
